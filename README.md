# The Consulting Room

An educational static website on Sigmund Freud and C. G. Jung.

## Open locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Copyright stance

This site does **not** host the Standard Edition, Jung’s Collected Works, the Letters, or the Red Book. It links to Project Gutenberg / Wikisource for U.S. public-domain titles and to official archives for the rest.
